# Implementing Missing Features
## Proposed Changes
### Web
- **Profile Picture Upload**: Add image upload capability to the profile page.
- **Cover Letter Generation**: Add a button to generate cover letters based on profile and job description.
- **Autonomous Application**: Add a toggle for users to approve autonomous applications.

### Backend
- **Profile Picture Endpoint**: Add an endpoint to handle image uploads and store URLs in the database.
- **Cover Letter Endpoint**: Create an AI endpoint for cover letter generation.
- **Autonomous Settings**: Add endpoints to update autonomous application preferences.

### Mobile
- **Profile Picture Upload**: Add image picker to the mobile profile screen.
- **Cover Letter Generation**: Implement the cover letter generation API call.
- **Autonomous Application**: Add the toggle to the mobile profile screen.
